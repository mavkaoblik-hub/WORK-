# Еталон успішного складання Excel XLSM — Offline v9

> **НЕ ПЕРЕПИСУВАТИ ЦЕЙ МЕХАНІЗМ** під час наступних змін інтерфейсу, форм введення, статусів рейсів, каталогу маршрутів чи формул. Вважати за стабільний технічний конвеєр складання.

## Підтверджений результат

**21 жовтня 2026 року**, користувач успішно створив книгу `Транспортний_центр.xlsm` у **Microsoft Excel LTSC для Windows** через комплект `Transport_Center_Offline_v9.zip`. Скриншот консольного встановлення підтвердив усі 5 етапів, наявність `xl/vbaProject.bin` і 114 вбудованих маршрутів. Подальші скриншоти демонструють, що XLSM відкривається, кнопки відображаються і VBA-форма `InputBox` для «Закрити рейс» запускається. **Повне функціональне тестування всіх кнопок ще не завершено.**

**Застереження:** цей репозиторій може не містити бінарний оригінал ZIP; хеші засвідчують конкретну успішно перевірену поставку. Не плутати з попередніми v4–v8.

## Відтворювана послідовність складання

1. **Офлайн-пакет** зберігає локально `Транспортний_центр_v8_робочий_Times_New_Roman.xlsx`, `vba/TransportCenter.bas`, `data/routes_europe.json`, `INSTALL_OFFLINE.ps1`, `START_INSTALL.cmd`, файли відновлення копій. На ПК замовника **немає завантаження з GitHub**.
2. `START_INSTALL.cmd` викликає **Windows PowerShell 5.1** з UTF-8, інсталятор запускає власний прихований `Excel.Application` через COM, з `DisplayAlerts=False`, `EnableEvents=False`, `AskToUpdateLinks=False`, `AutomationSecurity=3`.
3. **Спочатку `Workbooks.Add()`** (тимчасова книга), **потім** `Application.Calculation=-4135` (manual), **лише потім** відкриття вихідного XLSX: на LTSC встановлення Calculation без відкритої книги викликало `0x800A03EC`. Так запобігаємо перерахунку старих вебформул.
4. На тимчасовій книзі **завчасно перевірити** доступ до `VBProject.VBComponents.Add(1)` і `CodeModule.AddFromString()`, видалити пробний модуль. Для одноразового встановлення потрібний дозвіл **Trust access to VBA project object model** (без обходів політик; вимкнути після завершення).
5. Відкрити копію XLSX, створити/заповнити локальні довідники, **114 маршрутів** із `data/routes_europe.json`, форми на аркушах і кнопки. `Range.NumberFormat` і `NumberFormatLocal` на деяких LTSC можуть відмовити: це косметична помилка, не зупиняти збірку; значення та формули зберігати.
6. Для числових записів **не використовувати прямий `Range.Value2 = [double]`**: в цьому середовищі виникав `System.Double -> System.String`. Перетворити число через `InvariantCulture` і записати як числову формулу-літерал `cell.Formula = '=' + invariantNumber`; передавати в COM **скалярні** значення по комірках, не вкладені `Object[]`.
7. Прочитати локальний VBA-файл як UTF-8 через `ReadAllText`, прибрати службову строку `Attribute VB_Name`, створити стандартний модуль `VBComponents.Add(1)`, встановити ім'я `TransportCenter`, виконати `CodeModule.AddFromString(source)`. Це зберігає **кирилицю** без ANSI-імпорту `.bas`.
8. Створити `Shapes.AddShape` та призначити `OnAction` із посиланням на VBA-процедури цієї книги. Вкладку **«Зміст» залишити першою**; шрифт Times New Roman, робочі підсумки й формули зберегти.
9. Перевести перерахунок у automatic (`-4105`), наскільки дозволяє Excel; **`SaveAs(target, 52)`**, де 52 = `xlOpenXMLWorkbookMacroEnabled`.
10. **КРИТИЧНО:** після `SaveAs` книга залишається відкритою. Тому **спочатку `book.Close(False)`, закрити guard, `excel.Quit()`, звільнити COM/GC** — і лише **потім** відкривати отриманий XLSM через `ZipArchive` для перевірки `xl/vbaProject.bin`, `xl/workbook.xml`, `[Content_Types].xml`. Для тимчасових блокувань Windows використовувати обмежений цикл повторних спроб з `FileShare.ReadWrite`. Раніше негайний `File.OpenRead` спричиняв «used by another process».
11. Створити локальну папку `_Резервні_копії`, не перезаписувати вихідний XLSX, не перезаписувати існуючий XLSM без підтвердження. Після інсталяції **ніяких звернень до GitHub**. NBP лише за окремою ручною командою користувача.

## Правило для наступної розробки

**НЕ повертатися до схеми v4–v8 і НЕ впроваджувати новий установлювач з нуля.** Наступна робота — редагування UX і VBA: головна панель адміністратора, діалогові вікна замість переходів між листами, вибір рейсів зі списку, статуси рейсу, приховані технічні вкладки, скасування закріплення областей. При цьому послідовність COM/VBA/SaveAs/Close/ZIP вище залишається незмінною. Після кожного редагування потрібні статичні перевірки, а потім запуск у Excel LTSC.

Цей запис фіксує фактично успішну **методику складання**, а не сертифікує всю бізнес-логіку XLSM.

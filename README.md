# Транспортний центр — Excel ERP

Розробка макросної книги для обліку автоперевезень на основі **Транспортний центр v8**.

## Статус
- VBA-кнопки та легка панель адміністратора розробляються у `vba/TransportCenter.bas`.
- Збірка `.xlsm` виконується локально **в Microsoft Excel для Windows** через `tools/INSTALL.ps1` — лише на комп'ютері, де є Excel.
- Перед змінами створюються копії у каталозі `_Резервні_копії`.
- Готові робочі дані водіїв не повинні потрапляти в публічний репозиторій.

## Важливо щодо безпеки
Репозиторій наразі **публічний**. Не завантажуйте сюди персональні дані водіїв, реальні маршрути, платежі та резервні копії.

## Інсталяція
1. Завантажте код цього репозиторію ZIP та розпакуйте.
2. Покладіть поруч із `START_INSTALL.cmd` файл `Транспортний_центр_v8_робочий_Times_New_Roman.xlsx`.
3. Закрийте Excel; запустіть `START_INSTALL.cmd`.
4. Скрипт збереже новий `Транспортний_центр.xlsm` (оригінальний XLSX залишиться незмінним).
5. Якщо доступ до VBA Project заборонений, скрипт пояснить одноразове налаштування **Trust access to the VBA project object model**. Умикайте його лише для цієї інсталяції і вимикайте після завершення.
6. Перед запуском макросів у Excel перевірте довіреність джерела файлу; не вмикайте макроси в невідомих книгах.

## Функції
- «Заповнити дані» — панель адміністратора з вибором водія, автоматичною датою, контрольованими полями.
- «Додати водія» — копія еталонного аркуша, реєстрація у змісті та звітах.
- «Оновити дані» — перерахунок/оновлення підтримуваних підключень; онлайн-тарифи паркінгів потребують окремого перевіреного завантажувача.
- «Звіти» — перехід до наявних графіків.
- «Закрити рейс» — контроль і фіксація закриття в журналі.
- «Резервна копія» — збереження поточної версії до `_Резервні_копії`.
- «Відновлення» — окрема команда `RESTORE_BACKUP.cmd` із підтвердженням, коли Excel закритий.

## Межі тестування
Перевірка тексту макросів, структури початкового XLSX та наявності очікуваних колонок проводиться автоматично. **Запуск VBA у Microsoft Excel LTSC і готова .xlsm-збірка на реальному Windows залишаються непідтвердженими, поки не запущено інсталятор у Excel**.


## Випуск 0.2 — легка панель адміністратора

На вкладці **«Зміст»** встановлюються кнопки:
«Заповнити дані», «Додати водія», «Звіти», «Резервна копія»,
«Оновити з інтернету», «Закрити рейс», «PDF-звіт», «Відновити копію».

**Заповнити дані:** перехід на `Форма_адміністратора`. B5 — випадаючий
список водіїв із реєстру; B6 — дата нарахування (сьогодні);
B7 — замовник; B8 — маршрут; B9/B10 — виїзд/прибуття (початково сьогодні);
B11/B12 — одометр; B13 — дохід USD; B14 — отримана оплата USD (початково 0);
B15 — кермування; B16 — простій; B17 — примітка; B18 — втрати часу.
Кнопка «Зберегти рейс» створює ID і записує дані одночасно у журнал водія
(рядки 13–92) та `Нарахування` (рядки 13–132), не змінюючи розрахункові
колонки. Перед записом створюється резервна копія, після — книга зберігається.

**Закрити рейс:** контроль статусу «OK» та витрат за ID, після чого у
`Нарахування` колонки L:N фіксують закриття, дату й користувача.

**PDF-звіт:** зберігає поточний аркуш `Звіти` у локальну папку `_Звіти`.
Рік звіту встановлюється на вкладці `Звіти`, комірка B5.

**Відновлення:** Excel не можна безпечно перезаписати, доки він відкритий.
Кнопка відкриває папку копій; потім потрібно закрити Excel й запустити
`RESTORE_BACKUP.cmd`. Перед відновленням зберігається поточна версія.

### Мережа — тільки вручну

ЖОДНИХ мережевих звернень під час відкриття, введення даних чи
натискання F9. Інсталятор прибирає `WEBSERVICE`/`FILTERXML` з
технічного аркуша й онлайн-колонок, зберігаючи історичні значення.
**Тільки кнопка «Оновити з інтернету»** робить запит до API NBP для
USD/PLN, зберігаючи котирування та його дату. **Тарифи паркінгів поки
не завантажуються цією кнопкою**: механізм HTML-парсингу потребує
окремого тестування. Система залишає їхні попередні значення.

### Перевірки й обмеження

У `.github/workflows/validate.yml` налаштовані:
(1) перевірка контрактів VBA, що мережевий виклик можливий лише з
окремої процедури; (2) синтаксична перевірка PowerShell на Windows runner.
За бажанням структуру вихідної книги можна перевірити командою
`python tests/check_project.py "Транспортний_центр_v8_робочий_Times_New_Roman.xlsx"`.

Це **не** виконує VBA та не підтверджує сумісність із Excel LTSC.
Перед використанням реальних облікових даних потрібно отримати
перший результат запуску `START_INSTALL.cmd` у ліцензованому
Microsoft Excel для Windows і провести контрольне створення,
закриття та відновлення тестового рейсу.

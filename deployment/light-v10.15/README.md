# Транспортний центр — v10.15 LIGHT (CLEAN)

Окрема гілка `feature/v10.15-light-dashboard` побудована на перевіреному clean v10.14.8; робочу збірку не змінено.

## Інтерфейс

- Біле та світло-сіре тло замість темного.
- 8 білих карток KPI з контрастними темно-зеленими числами.
- 16 діючих навігаційних кнопок, збережено прив'язку до наявних макросів.
- Спокійні м'ятні акценти та шрифт Segoe UI у панелі й формах.
- Світле оформлення `Поточний стан`, `Архів рейсів` та `Курси валют`.

Схему обліку, формули у журналах, конвертацію FX, механізм збереження/резервування й VBA події книги не змінювали. Нульова база зберігається; 114 маршрутів лишаються довідником. Старий пакет v10.14.8 залишається резервною стабільною збіркою.

## Інсталяція

1. Завантажте **повний ZIP CLEAN LIGHT** із чату (з початковою `.xlsx`).
2. Розпакуйте всі файли у **нову порожню папку Windows**.
3. Закрийте Excel, запустіть `START_INSTALL.cmd`.
4. Якщо необхідно, тимчасово дозвольте довірений доступ до VBA project object model у Центрі безпеки Excel, після інсталяції вимкніть.
5. Перевірте кнопки нового рейсу, зміни статусу, поточний стан, архів, курси валют, фінансові звіти й повернення стрічки після закриття.

Інсталятор не перезаписує існуючий `.xlsm`.

## Файли вихідного коду

- `DESIGN_LIGHT.ps1` — незалежний шар оформлення, **не** редагує облікові журнали.
- `INSTALL_LIGHT.ps1` — інсталятор чистої книги з імпортом нової теми.
- `TransportStatusFX.bas` — лише змінена палітра поточного стану та архіву.
- `tests/check_light_115.py` — контроль 8 карток, 16 дій, відсутності demo-seed і сумісних FX декларацій.
- `.github/workflows/validate-light-115.yml` — статичні перевірки і парсинг PowerShell 5.1 у Windows CI.

**Обмеження перевірки:** GitHub Actions перевіряє джерела та синтаксис PowerShell, але не виконує Microsoft Excel COM та VBA. Реальну роботу інтерфейсу потрібно підтвердити в Excel LTSC на комп’ютері користувача.
